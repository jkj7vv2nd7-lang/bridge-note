# Bridge Note ― 保護者コミュニケーション＆ログ整理支援（プロトタイプ）

教員の生メモから保護者への連絡文を3パターンに整え、児童・生徒別カルテと面談メモの構造化を支援するツール。情報は端末内（localStorage）のみに保存し、外部送信しません。

## 構成

- `index.html` ― アプリ本体（単体HTML、CSS/JS内蔵）
- `icon.png` / `icon-180.png` ― アイコン（橋＋開いたノートと鉛筆）
- `og.png` ― SNS共有時のプレビュー画像

## 起動方法

- `index.html` をブラウザで開くだけで動作します（サーバー不要）。
- 公開する場合：GitHub Pages に一式をそのまま置けば配信できます（リポジトリ作成と Pages 有効化は清水さんの操作）。

## 使い方

### 連絡文づくり（3ステップ）
1. 種別（トラブル報告／忘れ物注意／生活態度・体調／行事案内／ポジティブ）・トーン（丁寧・共感／簡潔・事実／穏やか／厳しめ）・児童・生徒（任意）を選ぶ
2. 生メモを書く → 「3パターンの文章を作る」
3. 「共感アプローチ」「事実確認重視」「改善ステップ提案」が同時生成される。調整チップ（柔らかく／期限を強調／短く／感謝／しっかり）や自由入力で再調整し、コピーして使う

### ローカル変換エンジンの仕組み
- APIキーなしで完全に動作します。種別×トーンのパターン部品、生メモの文末丁寧化ルール（〜だった→〜でした等）、日付・持ち物の自動抽出、カルテ履歴からの「前回○月○日の面談でお話しした件の続きですが」というつながり文を組み合わせて組み立てます
- 児童・生徒を選んで生成すると、「この連絡をカルテの履歴に記録する」ボタンで履歴に残せます

### 児童・生徒カルテ
- 名前・特記事項・家庭環境メモ・連絡/面談の履歴タイムラインを端末内に保存。追加・編集・削除（確認つき）。履歴は1件ごとに「✏️ 直す／🗑 消す」で加除訂正でき、特記事項・家庭環境メモはカルテの「編集」から直せます

### 面談ボード
- 面談中のメモ：面談ボードの先頭にある大きなメモ欄。書いたそばから自動保存され、日付と児童・生徒を結びつけてカルテの履歴（面談）に全文のまま残せます。「この内容で構造化する」でワンタップで下の構造化ボードへ送れます
- 殴り書きや文字起こしを貼ると、ルールベースで4カード（①保護者の要望・心配 ②学校側の説明 ③約束事 ④引き継ぎ要約）に振り分け。カードは編集可能で、Markdown／テキストでコピーできます。振り分けは目安である旨を画面に明記しています

- 元のメモとカードは端末内に自動保存され、次に開いたときも残ります（「ボードを消去」でまとめて消去）。連絡文の生メモと選択中の種別・トーンも同様に自動保存されます

### 任意AIモード（初期オフ・個別支援プランの道具と同じ仕様）
- 接続先を切り替え可能：Google Gemini／OpenAI／Anthropic Claude／OpenAI互換サービス／Ollama
- APIキーとモデルはサービスごとに端末内へ保存。接続テストボタンつき
- オンにした場合のみ、生成済みの文章をAIで仕上げるボタンが現れます。使うときに文章がAI提供元へ送信される旨を画面に明記しています
- キーがない／AIオフの場合は、ローカル変換エンジンで生成します（こちらが本体です）

## 検証済み（2026-11-14、ヘッドレスChrome実測）
- カルテ追加・履歴追加・削除確認、児童・生徒を選んだ生成（履歴のつながり文が入ること）、3パターン生成、調整チップ（期限強調の行が入ること）、自由入力の調整（感謝・柔らかく）、生成→カルテ記録、面談ボードの分類（サンプルで①②③が正しく振り分け）、Markdown整形、ダークモード、AI初期オフ ― すべて動作、ページエラーなし

## 未確認・制約
- 実機（iPhone）での操作感は未確認
- 任意AIモードの実キーでの通信は未確認（接続テストのエラー表示までは確認済み）（キーをお持ちでない場合はオフのままで全機能が使えます）
- データはブラウザの localStorage のため、端末・ブラウザを変えると引き継がれません。正式な記録は学校の記録にも残してください（アプリ内にも明記）
- バックアップ（簡易変更履歴）：メモ類（面談中メモ／連絡文の生メモ／面談ボード／カルテのメモ／カルテ履歴）を直したり消したりする前に、前の内容を日時つきで端末内に自動保存します。設定画面の「🕘 バックアップ（変更履歴）」から内容の確認と復元ができます。保持はメモ欄ごとに最新20件・全体150件まで
